# 0.3.0 验证记录（2026-10-21）

## 本轮实际执行

- 使用现有 Windows x64 / CPython 3.12.14 / Node 24.5.0 / FFmpeg 9.0.2、既有 small 模型与锁定依赖，setup 检查通过。
- 默认 setup 的合成片端到端自检通过：1 秒合成视频及静音轨 → probe、候选切镜、抽帧、ASR → HTML、素材池 JSON/CSV。模型文件 SHA256 和本地依赖版本检查通过。
- 离线单元测试 4 项通过：错误哈希保留原文件、损坏模型修复且正确文件不重下、ZIP 路径穿越拒绝、模拟 Node ZIP 安装并保留许可。测试使用内存下载响应，没有联网安装软件。
- 隔离本地 Git 仓库验证 5 项通过：快进更新后调用 setup、脏工作树停止并保留修改、提交分叉停止并保留 HEAD、安装 clone 后调用 setup、目标已存在时拒绝覆盖。该测试的 setup 使用回调替身，不重复执行 ASR。
- PowerShell 语法检查及 Codex 技能格式检查通过。
- 空运行时仅检查测试正确返回失败，并列出工具、依赖和模型缺失；没有触发下载。

## 未测试及限制

- 未在另一台干净电脑完成 Python/Node/FFmpeg/全部 wheel/模型的真实联网安装。上述版本的下载与安装分支不应被描述为全新机器验证通过。
- FFmpeg 自动下载锁定 8.1.2，实际端到端复用已有 9.0.2；Node 自动下载锁定 22.16.0，实际端到端复用已有 24.5.0。
- 本机 Node 官方下载源读取出现过网络 TLS 失败；其他机器也可能受网络限制。安装失败应保留具体缺件和错误，不声称自动补齐成功。
- 脚本实际在当前 PowerShell 7 环境执行。Windows PowerShell 5 的脚本执行被本机策略禁止，未修改策略，也不宣称该环境通过。
- 浏览器 UI、完整页面截图、另一部真实视频、Linux/macOS 均未测试。合成片自检不代表导演分析正确性、完整听审或复刻效果验收。

Gyan 版本、文件名和校验值来自 [发行构建页](https://www.gyan.dev/ffmpeg/builds/)。Node 校验文件在安装时从同一固定版本的 nodejs.org 获取并验证 ZIP；不把 Node 哈希写死为未经取得的值。

# 素材池与脚本优化交接

统一入口为 `asset-pool.json`，schema `film-reference-pool/v1`。保存源文件身份、审核记录、单镜、语言、ASR证据、镜头组和技能来源。路径以池文件所在目录为基准。截图、原片和数据一同保留；移动目录后重新检查路径。

单镜保留 aipi 字段，并可附：

- `recordType`: shot / transition。黑场是时间轴事件，不一定计为内容镜头。
- `fiveDimensions`: 构图、焦距感／心理距离、运镜动机、剪辑理由、叙事功能。
- `generationPrompts`: storyboard、video、status、source。提示词属于创作建议。
- `oldShotIds` 与 `evidence`: 修订前镜号和证据，避免派生文件引用失效。

镜头组JSON为数组，每条包含id、shotIds、mechanism、conditions、limits、tags、reviewState。每个镜号必须存在；不把单条案例的镜数、时长、对白或特效提升为普遍规则。

下游按新故事的关系、情绪、认知差、道具、反转、调度等标签检索，优先读取镜头组的完整因果，再查看单镜。交接时列出素材ID及证据、借鉴理由、调整条件、审核缺口。未提供新剧本时仅交资料包，不凭空创作新故事。

画面事实、五维解读和两类提示词分栏；字幕与ASR分开呈现。标记 `verified` 也必须说明核了什么来源；字幕已核不等于音轨已核。用户认可展示或识别结果，只记录对应验收范围。

此素材池是脚本优化技能的案例输入，不是它的权威运行规则或自动知识入库。本技能不会因产物存在、ASR返回10条、用户说“没问题”就推定全片动态与音效听审完成。

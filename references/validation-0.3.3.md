# 0.3.3 普通账号在线安装与公开分发验证（2026-10-22）

## 实测环境

Windows x64 联网宿主的实际管理员令牌检查为 false，测试脚本遇到管理员令牌会拒绝执行。没有使用 RunAs、UAC 管理员提升、全局执行策略修改或全局依赖安装。基础 Python 3.12 与 Git 由宿主提供，运行时目录为空，Node.js/FFmpeg 从测试 PATH 隐藏，未复用旧模型或识别库。

宿主通道在 Codex 工具层面离开了离线沙箱，但进程仍是普通 Windows 用户；不能把该结果描述为离线沙箱无需联网授权。CodexSandboxOffline 的 GitHub 连接失败仍保留在上一轮记录中，公开仓库不会改变宿主网络政策。

## 公开与匿名访问

用户明确确认原始示例视频、逐镜截图、对白、分析和历史可以一并公开后，仓库改为 PUBLIC。禁用 credential.helper 和交互提示后的真实 ls-remote 与独立 clone 均通过。读取公开仓库不再需要 GitHub 账号。

## 实际测试结果

- 冷安装：普通 Windows 令牌，实际下载 Node.js 22.16.0、FFmpeg 8.1.2、26 个 PyPI 依赖、small 模型。首次运行在最后一个 vocabulary.txt 文件出现网络 EOF 后失败，保留失败日志，不记为首次一次通过。
- 恢复及匿名更新：禁用 Git 凭据，运行 update.ps1；仅补齐缺失词表，模型哈希、依赖/native import 及合成片自检通过。无需管理员权限，也没有重下已正确的大模型文件。
- 真实影片：同一普通令牌与本轮新运行时完成 probe、候选切镜、18 张抽帧、10 段机器转写及 HTML/素材池导出；候选镜头 9 条。仍是待 Agent 分析的证据底稿，不代表全片听审或新导演分析验收。
- 分发案例修复：补齐 study.final.json 所引用但分发漏带的 asr/transcript.raw.json，清除本机绝对路径，保留原机器分段/逐词文本和时间戳；完整案例重新导出为 9 条镜头、10 段机器结果、1 个镜头组，原审核状态保留。
- 回归测试 10 项通过，包含完整案例重新导出测试。README 可复制 PowerShell 安装命令的语法检查通过。

## 范围与限制

初始 clone 发生在改公开前，使用原有仓库访问权；改公开后另行禁用凭据 clone，且更新匿名执行。组件下载是本轮真实冷下载，不是复用此前测试的运行时。

缺 Python 时的 winget 分支、缺 Git、另一台全新 Windows 电脑、Linux/macOS、浏览器 UI 仍未测试。网络中断时需恢复网络后重跑同一安装/更新命令；有限重试不保证任意网络下必然成功。

脚本本身无需 Windows 管理员权限；所在 Agent 的工具/网络沙箱仍可能要求宿主放行，这不是仓库公开或安装脚本能够消除的限制。案例素材公开不改变原许可，也没有将所有模块统一改成 MIT。
